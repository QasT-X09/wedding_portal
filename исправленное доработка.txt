# ИСПРАВЛЕНИЕ 3D PHOTO CAROUSEL

Проанализируй текущий проект и исправь существующую 3D-карусель свадебных фотографий.

Я прикрепил два screenshot reference, которые показывают текущее состояние сайта.

Не создавай новую страницу с нуля.
Сначала найди существующую реализацию 3D-карусели и исправь её.

---

# 1. УБРАТЬ PANORAMA

Сейчас в проекте есть блок/надпись, связанная с:

**«3D ПАНОРАМА ЛЮБВИ»**

и концепцией panorama.

Эта концепция мне больше НЕ нужна.

Полностью убрать:

* «3D ПАНОРАМА ЛЮБВИ»;
* связанные с ней explanatory labels;
* лишний текст над каруселью;
* любые элементы, которые создают ощущение panorama viewer.

Не заменять её другим текстом.

Главный объект этой секции должен быть:

# 3D PHOTO CAROUSEL

То есть пользователь должен сразу видеть фотографии.

---

# 2. ГЛАВНАЯ ПРОБЛЕМА — КАРУСЕЛЬ НЕ ВРАЩАЕТСЯ

Сейчас фотографии расположены по кругу/в перспективе, но фактически стоят на месте.

Это НЕПРАВИЛЬНО.

Нужно реализовать настоящую 3D rotation animation.

Карусель должна постоянно и плавно вращаться вокруг своей вертикальной оси.

Принцип:

```text
          PHOTO
            ↓

PHOTO → CENTER → PHOTO
  ↑                 ↓
  └──── rotation ───┘
```

Пользователь должен визуально видеть, что фотографии движутся по кругу.

---

# 3. AUTO ROTATION

После загрузки секции:

3D-карусель автоматически начинает медленно вращаться.

Rotation должна быть:

* continuous;
* slow;
* smooth;
* infinite;
* cinematic;
* без рывков.

Не делать резких переходов между фотографиями.

Не делать:

```text
photo 1
jump
photo 2
jump
photo 3
```

Нужно ощущение настоящего вращающегося 3D-кольца.

Например концептуально:

```text
rotateY(0deg)
        ↓
rotateY(360deg)
        ↓
rotateY(720deg)
        ↓
infinite
```

Но не привязывайся буквально к этим значениям — реализуй качественную motion system.

---

# 4. FRAMER MOTION

Использовать существующий Framer Motion.

Если его нет:

```bash
npm install framer-motion
```

Использовать MotionValue / motion animation.

Для автоматической анимации можно использовать:

* `motion.div`;
* `animate`;
* `transition`;
* `repeat: Infinity`;
* `ease: "linear"` или эквивалентную плавную easing-систему.

Для ручного управления использовать MotionValues / drag logic.

Не использовать постоянные React state updates для animation loop.

---

# 5. 3D STRUCTURE

Карусель должна быть построена как настоящее 3D-пространство.

Использовать:

```css
perspective
transform-style: preserve-3d
rotateY
translateZ
```

Каждая фотография должна находиться на окружности.

Концептуально:

```text
              PHOTO
                │
                │
       PHOTO ───┼─── PHOTO
                │
             PHOTO
```

Но визуально пользователь видит перед собой центральную фотографию, а остальные фотографии находятся по бокам и постепенно уходят в глубину.

---

# 6. CENTRAL PHOTO

Центральная фотография:

* самая большая;
* самая яркая;
* максимально резкая;
* находится ближе всего к пользователю.

Боковые фотографии:

* меньше;
* имеют perspective;
* слегка темнее;
* находятся дальше;
* могут иметь subtle blur;
* должны создавать глубину.

При вращении новая фотография постепенно становится центральной.

---

# 7. ПЕРЕХОД ФОТОГРАФИЙ

Когда фотография перемещается:

```text
RIGHT
 ↓
CENTER
 ↓
LEFT
```

она должна плавно менять:

* scale;
* translateZ;
* rotateY;
* opacity;
* brightness.

Пример состояния:

```text
CENTER:
scale: 1
translateZ: максимальный
opacity: 1

SIDE:
scale: ~0.75–0.85
translateZ: меньше
opacity: ~0.5–0.8
```

Значения подобрать визуально самостоятельно.

---

# 8. НЕ ОСТАНАВЛИВАТЬ КАРУСЕЛЬ

Карусель не должна просто стоять на месте после загрузки страницы.

Она должна вращаться автоматически.

Также не делать так, чтобы rotation происходила только после клика.

Нужны одновременно:

### Automatic rotation

Карусель сама медленно вращается.

### Manual interaction

Пользователь может:

* drag мышью;
* использовать mouse wheel;
* нажимать стрелки;
* на мобильном делать swipe.

---

# 9. PAUSE ON INTERACTION

Когда пользователь взаимодействует с каруселью:

* mouse drag;
* touch drag;
* swipe;

автоматическую rotation временно приостановить.

После окончания взаимодействия:

через небольшой delay плавно возобновить auto rotation.

Не делать резкого старта.

---

# 10. MOBILE

На смартфоне обязательно:

```text
touch swipe
```

Пользователь должен провести пальцем:

← →

и карусель должна вращаться в соответствующую сторону.

На мобильном уменьшить количество видимых боковых фотографий.

Центральная фотография должна оставаться главным объектом.

Не ломать layout на:

390×844
393×852
430×932.

# 15. GOLDEN RING

Золотое 3D-кольцо под фотографиями должно остаться.

Но теперь оно должно визуально поддерживать вращение карусели.

То есть:

**кольцо и фотографии должны восприниматься как одна 3D-система.**

Кольцо:

* champagne gold;
* thin;
* subtle glow;
* elegant;
* low intensity.

Оно не должно выглядеть как толстый пластиковый круг.

# 16. GOLDEN RING ROTATION

Важно:

Если в текущем проекте golden ring просто нарисован и стоит неподвижно — исправить это.

Кольцо должно иметь собственную очень медленную rotation animation.

Но скорость кольца должна отличаться от скорости карточек.

Например:

```text

GOLDEN RING
even slower rotation
```

Обе анимации должны быть плавными.

Не синхронизировать их жёстко, если это выглядит искусственно.

---

# 17. FALLING PETALS

Падающие лепестки оставить.

Они должны работать и здесь.

Использовать тот же visual style, что на первой странице.

Лепестки:

* падают сверху вниз;
* имеют разную скорость;
* имеют разные размеры;
* вращаются;
* имеют небольшую горизонтальную траекторию;
* создают depth;
* некоторые находятся перед фотографиями;
* некоторые находятся за фотографиями.

Не использовать одинаковые лепестки с одинаковой траекторией.
