# 💍 Wedding Guest Media Portal & Live Wall

Интерактивный свадебный медиа-портал для сбора и мгновенной трансляции воспоминаний от **300 гостей** через QR-код с живым слайд-шоу для проектора и автоматической AI-сортировкой сюжетов.

Разработан совместно с консилиумом моделей **Google Gemini 3.6 Flash** (системная архитектура, AI-тегирование) и **Mistral Codestral** (потоковый бэкенд, асинхронные очереди, валидация квот).

---

## 🌟 Ключевые возможности

1. **📲 Вход для гостей по QR-коду**:
   - Сканирование QR-кода на столе или пригласительном.
   - Ввод имени/семьи, номера стола и тёплого пожелания молодым.
   - Сохранение сессии в телефоне (localStorage).

2. **📸 Строгие лимиты и защита сети**:
   - **До 25 фото** и **до 10 видео** на каждого гостя (счётчик обновляется в реальном времени).
   - До **30 МБ за фото** и до **500 МБ за видео**. Файлы сохраняются на сервере в исходном формате; видео пишется потоково, без загрузки целиком в оперативную память.

3. **🎥 Режим «Проектор в зале» (`/#live`)**:
   - Полноэкранный кинотеатр для банкетного проектора.
   - Кинематографический эффект плавного зума **Ken Burns**.
   - Анимированный романтический фон с золотыми искрами и лепестками.
   - **Real-Time SSE пуш**: при загрузке фото гостем всплывает золотое уведомление с его именем и пожеланием, и фото сразу выводится на экран.
   - QR-код в углу экрана, чтобы гости могли сканировать его прямо с проектора.

4. **🤖 Умная автосортировка и AI-тегирование**:
   - Автоматическая классификация сюжетов по категориям:
     - 🥂 *Тосты и застолье*
     - 💃 *Танцы и драйв*
     - 👥 *Гости и друзья*
     - 💍 *Детали и кольца*
     - 🎂 *Свадебный торт*
     - 👰 *Молодожёны и портреты*
   - Персональная сортировка по папкам гостей (`uploads/{Имя}_{id}/`).
   - Фильтры в галерее по гостям и сюжетам.
   - **Скачивание в 1 клик**: экспорт всей свадьбы или отдельной категории в ZIP-архив.

5. **🏷️ Печать карточек для столов (`/#qr`)**:
   - Готовый красивый свадебный макет для печати на столы с индивидуальным QR-кодом.

## 🚀 Быстрый запуск

### 1. Запуск сервера:
```powershell
cd C:\Users\ASUS\Projects\wedding_portal
python run.py
```

### 2. Ссылки для доступа:
- **Локально на вашем компьютере**: [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **Для гостей со смартфонов (в одной сети Wi-Fi)**: `http://192.168.1.204:8000`
- **Экран Проектора в банкетном зале**: [http://127.0.0.1:8000/#live](http://127.0.0.1:8000/#live)
- **Галерея и AI-сортировка**: [http://127.0.0.1:8000/#gallery](http://127.0.0.1:8000/#gallery)
- **Печать карточек со столовыми QR**: [http://127.0.0.1:8000/#qr](http://127.0.0.1:8000/#qr)

## ☁️ Развёртывание в облаке (Public Domain)

Для выхода в интернет перед свадьбой:
- **Бесплатный туннель без аренды сервера**: 
  Запустить Cloudflare Tunnel или ngrok: `ngrok http 8000` — полученный URL автоматически сгенерирует работающий QR-код.
- **Облачный хостинг (Docker/VPS/Render/Railway)**:
  Вся база хранится в SQLite WAL (или подключается PostgreSQL).
